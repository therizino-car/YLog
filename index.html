구글 로그인으로 시트 읽기

이 페이지는 비공개 구글 시트 YLog-차계부의 충전기록·월별요약·주행기록 탭을, Google로 로그인한 본인 계정 권한으로 읽어 와요. 시트를 공개할 필요가 없어요.

  • 권한은 읽기 전용(spreadsheets.readonly)만 요청해요. 페이지가 시트를 수정할 수 없어요.
  • 로그인 토큰은 이 탭의 메모리에만 두고 저장하지 않아요. 약 1시간 뒤 만료되면 조용히 다시 받아 오고, 안 되면 다시 로그인 버튼이 보여요.
  • 로그인 전이거나 읽기에 실패하면 페이지에 내장된 오프라인 스냅샷을 보여 줘요.
  • 로그인은 https:// 주소(예: GitHub Pages)에서만 동작해요. 파일로 직접 열면 스냅샷만 보여요.

처음 설정: Google Cloud 콘솔에서 웹 애플리케이션용 OAuth 클라이언트 ID를 만들고, 승인된 JavaScript 원본에 이 페이지의 주소(예: https://아이디.github.io)를 넣은 뒤, HTML 상단 CONFIG.CLIENT_ID를 그 값으로 바꿔요.

출퇴근 메뉴: 같은 주행기록 탭(출발ETA·평균속도·날씨·기온 열 포함)으로 계산해요. 시간대 폭과 참고용 기준은 HTML 상단 CONFIG.COMMUTE에서 바꿀 수 있어요.

현재 페이지 원본:

추정kWh = 충전% × 81.3 kWh(추정 용량). 집 충전 금액은 다음 달 말 관리비로 청구되기 전까지 추정값이에요.
🚗 주행 = 직전 충전 직후 첫 운행부터 이번 충전 직전 운행까지(주행기록 탭). 배터리 사용 = 직전 충전 후 % − 이번 충전 전 %(주차·대기 소모 포함), 전비 = 주행 km ÷ 사용 kWh.
