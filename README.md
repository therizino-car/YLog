# YLog · Model Y

비공개 구글 시트(YLog-차계부)를 Google 로그인(읽기 전용 OAuth, `spreadsheets.readonly`)으로 읽어 보여 주는 테슬라 모델 Y 모바일 페이지예요. 로그인 전이나 읽기에 실패하면 페이지에 내장된 오프라인 스냅샷을 보여 줘요.

## 메뉴
- **📊 차계부**: 월별 주행거리·충전비·전비, 충전 기록(충전 블록 + 직전 충전 이후 주행 블록).
- **🚗 출퇴근**: `주행기록` 탭으로 계산하는 출퇴근 분석. 회사 / 반월동 955(10부제 주차장, 0으로 끝나는 날)를 토글로 나눠 보고, 출발 시각대별 소요 시간·내비 예상 대비 지연·요일별 평균·전력 사용과 추천 출발 시각을 보여 줘요. 경유가 있는 운행은 자동으로 빠지고, 직접 뺄 날은 `CONFIG.COMMUTE.EXCLUDE`에 적어요.

## 출퇴근 시간대 설정 (`index.html` 상단 `CONFIG.COMMUTE`)
| 설정 | 기본값 | 뜻 |
|---|---|---|
| `BIN_MIN_TO_WORK` | 20 | 출근 시간대 폭(분). 기록이 쌓이면 10이나 15로 줄여 더 잘게 나눠요 |
| `BIN_MIN_TO_HOME` | 60 | 퇴근 시간대 폭(분). 30으로 줄이면 30분 단위 |
| `RELIABLE_N` | 5 | 이보다 기록이 적은 시간대는 "참고용" |
| `RECOMMEND_MIN_N` | 3 | 추천 후보가 되려면 필요한 최소 기록 수(모두 미달이면 "데이터 부족") |
| `SIMILAR_SPREAD_MIN` | 5 | 퇴근 시간대별 평균 차이가 이보다 작으면 "언제 나와도 비슷해요" |

## 설정
`index.html` 상단 `CONFIG.CLIENT_ID`에 Google Cloud OAuth 클라이언트 ID(웹 애플리케이션, 승인된 JavaScript 원본 = 이 페이지의 https 주소)를 넣어요.
